# Changelog

## 1.0.0

- Forked the ox_target 1.18.1 interaction engine with preserved MIT attribution.
- Added Focus and Classic presentation modes.
- Added React/TypeScript Dark Precision NUI with compact and multi-action layouts.
- Added keycaps, option metadata, hold progress and inline action feedback.
- Added server and player Theme Creator persistence with five presets.
- Added ox_target, qb-target and qtarget replacement declarations and adapters.
- Added explicit/automatic ESX, QBCore, Qbox, ox_core and inventory bridge selection.
