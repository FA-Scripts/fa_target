# Changelog

## 1.0.0

- Forked the ox_target 1.18.1 interaction engine with preserved MIT attribution.
- Added Focus and Classic presentation modes.
- Added React/TypeScript Dark Precision NUI with compact and multi-action layouts.
- Added keycaps, option metadata, hold progress and inline action feedback.
- Added server and player Theme Creator persistence with five presets.
- Added ox_target, qb-target and qtarget replacement declarations and adapters.
- Fixed early ox_target export forwarding when the resource folder is named `fa_target` instead of `ox_target`.
- Added click-outside cursor dismissal and visible success feedback to the qb-target contract fixture.
- Fixed the Classic mode aiming dot so it remains visible while targeting before an interaction is found.
- Fixed DUI zone interactions to anchor to the configured zone position instead of the moving raycast hit point.
- Fixed explicit option keys so an action labelled `G` is not also triggered by slot `1`, default confirm `E`, or controller confirm.
- Added explicit/automatic ESX, QBCore, Qbox, ox_core and inventory bridge selection.
